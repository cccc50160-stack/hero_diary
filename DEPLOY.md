# Деплой — пошагово

Рекомендуемая связка (обе бесплатны на старте, без карты для Neon):
**Neon** (Postgres) + **Render** (сервер). Названия других сервисов (Supabase вместо Neon,
Railway/Fly.io вместо Render) даны как альтернативы — шаги аналогичны.

## 1. Бот в Telegram

1. Открой чат с **@BotFather**.
2. `/newbot` → придумай отображаемое имя → придумай username (обязательно заканчивается на
   `bot`, например `stepa_life_rpg_bot`).
3. BotFather пришлёт токен вида `123456789:AAExample...` — сохрани его, это `BOT_TOKEN`.

## 2. База данных (Neon)

1. Зарегистрируйся на [neon.tech](https://neon.tech) (можно через GitHub-аккаунт).
2. Создай новый проект — База данных создастся автоматически.
3. На странице проекта найди **Connection string** (обычно вида
   `postgres://user:password@ep-xxx.region.aws.neon.tech/dbname?sslmode=require`).
   Скопируй целиком — это `DATABASE_URL`.

## 3. Код на GitHub

1. Создай новый (можно приватный) репозиторий на GitHub.
2. Залей в него содержимое папки `life-rpg-miniapp` целиком (и `public/`, и `server/`).
3. Проверь, что `server/.env` **не** попал в репозиторий (в `.gitignore` он уже исключён) —
   секреты (токен бота, пароль БД) никогда не должны быть в git.

## 4. Сервер (Render)

1. Зарегистрируйся на [render.com](https://render.com), подключи GitHub-аккаунт.
2. **New → Web Service** → выбери свой репозиторий.
3. Настройки:
   - **Root Directory**: `server`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. Раздел **Environment** → добавь переменные:
   - `BOT_TOKEN` — токен из шага 1
   - `DATABASE_URL` — строка из шага 2
   - (`PORT` можно не указывать — Render подставит сам)
5. **Deploy**. Через пару минут Render выдаст рабочий https-адрес вида
   `https://твой-сервис.onrender.com` — это и есть адрес твоего мини-аппа.

> Бесплатный тариф Render "засыпает" после ~15 минут без запросов и просыпается ~30–50 секунд
> при следующем заходе — это нормально для личного проекта, просто первое открытие после
> паузы будет с небольшой задержкой. Если это будет мешать (у команды/друзей, не только у
> тебя) — платный тариф это убирает.

## 5. Подключить мини-апп к боту

1. У @BotFather: `/mybots` → выбери своего бота → **Bot Settings → Menu Button**
   → **Configure Menu Button** → вставь https-адрес из шага 4.
2. (Опционально, для полноценной карточки Mini App вместо просто кнопки меню) —
   `/newapp` в том же разделе, тот же URL.
3. Открой бота в Telegram (на телефоне или в десктоп-клиенте — **не в обычном браузере**,
   `Telegram.WebApp` там просто не появится) → нажми кнопку меню → мини-апп должен открыться
   и показать "☁️ Новый профиль — прогресс будет сохраняться автоматически".

## 6. Проверка, что всё правда работает

1. Отметь любой квест.
2. Подожди 2 секунды (автосохранение) и полностью закрой мини-апп.
3. Открой его снова — квест должен остаться отмеченным. Если да — синхронизация с БД
   работает.
4. Если внизу появляется предупреждение "⚠️ Не удалось сохранить на сервер" — проверь в логах
   Render (**Logs** в панели сервиса), что сервер вообще запустился и `DATABASE_URL`/`BOT_TOKEN`
   указаны верно.

## Если что-то не поднимается

- **Ошибка при старте про DATABASE_URL** — переменная не задана или опечатка в connection
  string (в Neon строка обычно требует `?sslmode=require` в конце — обычно уже есть в скопированной строке).
- **401 на каждый запрос из мини-аппа** — скорее всего `BOT_TOKEN` на Render не совпадает с
  токеном бота, через которого реально открывают мини-апп (например, тестировал с другим
  ботом). Проверь `npm test` в `server/` — если тест локально проходит, логика подписи верна,
  дело в конкретном значении токена на хостинге.
- **Мини-апп открывается пустым/белым экраном** — почти всегда открыт не через Telegram
  (тогда просто должен появиться "тестовый режим", а не пусто) либо Render ещё не проснулся
  после паузы (подожди ~40 секунд и обнови).
